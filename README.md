# Rhino 8 Sheet Tools

Rhino 8 for Windows 向けの Python スクリプト集です。モデル空間に A3/A4 の用紙枠を並べ、枠ごとに PDF 出力したり、Rhino のネイティブなレイアウトページへ変換したりできます。

> **検証状況:** Rhino 8 を使った実機での動作確認は、このリポジトリの公開前には行っていません。使用前にモデルのコピーで確認してください。

## スクリプト

| ファイル | 機能 |
| --- | --- |
| [`rhino8_sheet_create.py`](scripts/rhino8_sheet_create.py) | A3/A4 の用紙枠を `SHEET_FRAME` レイヤーに配置します。配置位置をマウス追従のプレビューで確認できます。 |
| [`rhino8_sheet_batch_pdf_v03.py`](scripts/rhino8_sheet_batch_pdf_v03.py) | `SHEET_FRAME` 上の認識可能な枠を読み取り、複数ページの PDF に出力します。 |
| [`rhino8_sheet_to_layout_v04.py`](scripts/rhino8_sheet_to_layout_v04.py) | 用紙枠を Rhino のネイティブなレイアウトページに変換します。 |

## 動作環境

- Windows 版 Rhino 8
- Rhino 8 に付属する ScriptEditor の Python 3 環境
- 対象モデルの単位: ミリメートル (mm)
- Python パッケージの追加インストールは不要です。Rhino の `RhinoCommon`、`rhinoscriptsyntax` などを使用します。

## インストールと実行

1. このリポジトリを ZIP でダウンロードして展開するか、`git clone` します。
2. Rhino で対象モデルを開き、必要なら複製してバックアップを作成します。
3. ScriptEditor で実行したい `.py` ファイルを開き、実行します。
4. スクリプトの案内に従って用紙・配置・出力を指定します。

## 基本的な使い方

### 1. 用紙枠を配置する

`rhino8_sheet_create.py` を実行します。A3/A4、縦横、列数・行数、縮尺の分母、枠間隔を指定した後、標準の平行投影 Top ビューで配置します。プレビューの基準点は用紙グリッドの左上です。Esc キーで配置を取り消せます。

列数・行数はそれぞれ 1〜30、縮尺は 0.001〜10000、用紙上の枠間隔は 0〜1000 mm です。モデル空間に閉じたポリラインを作成し、`SHEET_FRAME` レイヤーと用紙情報のユーザーデータを設定します。この段階では Rhino のネイティブなレイアウトページは作成しません。

### 2. 複数ページ PDF を出力する

`rhino8_sheet_batch_pdf_v03.py` を実行します。認識された用紙枠を上から下、各段では左から右の順に PDF 化し、保存先を指定します。解像度はスクリプト内で 300 DPI に設定されています。枠内に見えているモデル空間の表示内容が出力対象です。

### 3. ネイティブレイアウトに変換する

`rhino8_sheet_to_layout_v04.py` を実行します。各枠に対応した Rhino レイアウトページと Top の詳細ビューポートを作成し、縮尺を設定して詳細ビューをロックします。変換後は Rhino の通常のレイアウト印刷機能から出力してください。

既にこのスクリプトが作成したページがある場合、既定ではスキップします。置き換えを選んだ場合は、ツール固有の識別情報が付いたページだけを削除する前に、もう一度確認します。同名のユーザー作成ページがある場合は処理を停止します。

## 既知の制約

- 用紙枠は、XY 平面にある軸に平行な A3/A4 の長方形ポリラインに限られます。回転した枠、任意形状の枠、対応外サイズは対象になりません。
- 3 スクリプトともモデル単位を mm として扱います。作成・PDF 出力では、モデル空間の標準 Top ビューかつ平行投影が必要です。
- PDF 出力のページ順は、枠の Y 座標を約 10 モデル単位の段に丸めてから X 座標順に並べる簡易方式です。不規則な配置では意図と異なる順序になることがあります。
- PDF 出力はアクティブな Top ビューの表示を枠の範囲でキャプチャします。枠内に表示された注釈、補助線、用紙枠なども含まれる場合があります。
- レイアウトの詳細ビューはモデル空間の形状を参照します。変換時点の複製画像ではないため、後でモデルを編集するとレイアウト上の表示も変わります。
- このツールは印刷時の線幅・色・レンダリング設定や、複雑なビューポート構成を自動調整しません。

## 未実機検証事項

このリポジトリの準備ではスクリプトの内容と構成を確認しましたが、Rhino 8 上での実行・印刷はしていません。次の項目は利用環境で確認してください。

- 使用中の Rhino 8 ビルドで、PDF のページサイズ・縮尺・向き・ページ順が意図どおりか
- PDF の線幅、色、表示モード、注釈などが印刷設定に合っているか
- ネイティブレイアウトの詳細ビューが用紙枠ごとに正しい位置と縮尺で作成されるか
- `SHEET_FRAME` レイヤーがロックまたは非表示の状態、既存ページ名との競合、既存生成ページの置き換え時の挙動

まずモデルのコピーで 1 枚だけ試し、出力を確認してから複数枚で使用してください。
